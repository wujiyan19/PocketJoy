# 玩趣盒 1.0.1 · 缺陷修复

版本 `1.0.1`，内部版号 `1000001`。此次为兼容现有玩法与存档的修复更新，使用补丁版本号。保留 64 个独立入口、69 个原有玩法。

- 修正随机数精度；黑洞、漂移、拆螺丝通过生成器版本保留旧关卡恢复路径。
- 修复俄罗斯方块贴底与靠边旋转、乘客上车死局结算及撤销后再次计分、打砖块新增行分值。
- 隔离 Preferences 单字段读取异常，保护未读成功的磁盘数据；该字段在本进程中的新修改仍可能无法落盘。
- 更新安全区状态响应、方向控制与无障碍标签、三语启动提示和部分动画范围。
- 明确回归清单，隔离本地签名配置，补齐模拟器与桌面卡片验证记录。

## 下载与安装

- `LittleGames-1.0.1-release-unsigned.hap`：API 26 Release 模式的未签名 HAP，最低兼容 HarmonyOS 6.1.1 / API 24。
- `INSTALL.zh-CN.md`：签名安装步骤与验证范围。
- `SHA256SUMS.txt`：HAP 与安装说明的 SHA-256。

安装需使用自己的合法证书和适用设备 Profile。公开附件不含个人调试签名包、Profile、私钥或口令。工程内的本机签名放在忽略文件 `signing.local.json`；未配置时可构建未签名包。
