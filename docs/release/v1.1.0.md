# 玩趣盒 1.1.0 · 游戏目录与玩法更新

玩趣盒 1.1.0 提供 **60 个入口、65 个玩法**，覆盖六个分类。数学挑战包含五种题型，节奏落键包含两种模式。包名为 `com.littlegames.collection`，内部版本号为 `1001000`。[完整玩法目录](../../README.md#玩法目录)

## 从 1.0.1 升级后

毛线收卷、迷你餐厅、房间塔防和射击守城从公开目录撤下，原始战绩仍保存在本机。部分游戏换了展示名，中文的「消消乐」「泡泡龙」「雷电战机」分别改为「宝石三消」「彩泡弹射」「纵向战机」，英文的「Sokoban」改为「Warehouse Box Pusher」。搜索时请使用新名称。

- **动作游戏更看操作。** 钩索摆荡要先挂住锚点，再松手跃出。切水果需要划过目标，空气曲棍球按碰撞时的挥槌速度回弹。爬坡越野的新开普通、困难关卡需要收油或刹车，原有坡道存档沿用原规则。自动攻击生存的简单档新增侧面来敌。
- **益智游戏能看清下一步。** 填满数独时会标出冲突数字。麻将接龙和倒水排序遇到残局会提示当前可以采取的操作。点击群消的新开局按颜色数调整目标分，数学挑战改进了算式比较的出题方式。
- **个人最佳成绩更好比较。** 记忆翻牌按难度记录最少配对尝试次数，滑动拼图按难度记录最少步数。两款都单列旧版总分。信号反应显示最佳毫秒数，并读取原有分档成绩。
- **其他变化。** 大鱼吃小鱼会随玩家成长补充猎物与捕食者，并用红色虚线圈提示危险鱼。纵向战机写明有剩余生命撑过敌群即可获胜，休闲钓鱼显示本局钓获的鱼种数。推箱子提供 12 个固定挑战及随机关卡。[固定关卡制作记录](../art/warehouse-box-level-origins.md)

## 下载与安装

从 GitHub Release 下载以下三个附件。HAP 使用 HarmonyOS API 26 编译，适用于满足最低版本 HarmonyOS 6.1.1（API 24）的手机和平板。安装前须用自己的证书及适用设备的 Profile 签名。[GitHub Release](https://github.com/wujiyan19/PocketJoy/releases/tag/v1.1.0)

| 附件 | 用途 |
| --- | --- |
| `LittleGames-1.1.0-release-unsigned.hap` | Release 模式编译的未签名 HarmonyOS 开发包 |
| `INSTALL.zh-CN.md` | 中文签名、安装和保留数据升级步骤 |
| `SHA256SUMS.txt` | 下载的 HAP 和安装说明的 SHA-256 校验值 |

已安装 1.0.1 的用户，沿用原签名覆盖安装可保留本机数据。新开普通、困难爬坡局采用新的地形格式，跨设备接续这类对局时请将接收端也升级到 1.1.0。[安装与升级步骤](v1.1.0-INSTALL.zh-CN.md)

## 验证范围

此前的玩法整改通过了 39 套桌面回归，共 1474 项。该次签名包在 API 26 模拟器逐一打开了 19 款游戏，核对了 60 个目录入口，并对滑动拼图结算、钩索松开限制、切水果划切、钓鱼抛竿等代表操作做了专项检查。[19 款整改记录](../game-retention-gemini-2026-11-22.md)

本次 1.1.0 的 39 套桌面回归共 1,474 项全部通过。API 26 模拟器从此前本地签名的 60 入口 1.0.1 修订包覆盖升级。强停重启后仍显示已玩 27 款、累计开局 47 次、3×3 滑动拼图最佳 22 步。11 月 5 日发布的 64 入口包未参与这次升级实测。[桌面回归结果](v1.1.0-regressions.json)
