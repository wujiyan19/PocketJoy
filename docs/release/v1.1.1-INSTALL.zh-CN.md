# 玩趣盒 1.1.1 安装与覆盖升级

本开发包面向 HarmonyOS 6.1.1（API 24）及以上的手机和平板，使用 API 26 构建。包名为 `com.littlegames.collection`，版本为 `1.1.1`，内部版本号为 `1001001`。公开 HAP 为未签名的 Release 构建，安装前需要自己的应用签名与设备授权。[下载 v1.1.1](https://github.com/wujiyan19/PocketJoy/releases/tag/v1.1.1)

## 1. 核对下载文件

将三个附件保存到同一目录。在该目录打开 PowerShell，分别核对 HAP 和安装说明的 SHA-256。每个文件的计算结果都应与 `SHA256SUMS.txt` 中同名文件的值一致。

```powershell
Get-Content -LiteralPath .\SHA256SUMS.txt
Get-FileHash -Algorithm SHA256 -LiteralPath .\LittleGames-1.1.1-release-unsigned.hap, .\INSTALL.zh-CN.md
```

## 2. 签名并安装下载的 HAP

也可以在手机上使用轻启·安装器签名安装。以下步骤适用于用电脑签名和安装。[轻启安装步骤](https://github.com/wujiyan19/PocketJoy/blob/v1.1.1/README.md#下载与安装)

1. 准备 Huawei DevEco Studio 26.0.0.851 或兼容 API 26 的工具链。连接设备，启用开发者调试并完成设备授权。将 SDK 的 `toolchains` 目录加入 PATH 后，运行 `hdc list targets` 确认能看到目标设备。
2. 用华为官方 HAP 签名工具、自己的签名证书和匹配该应用与目标设备的 Profile，对 `LittleGames-1.1.1-release-unsigned.hap` 签名。以下命令假设签名输出命名为 `LittleGames-1.1.1-signed.hap`。[华为应用签名指引](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing)
3. 只连接一台设备时，执行以下命令安装并启动。连接多台时，用 `hdc -t 设备标识 install -r 文件名` 选择上一步列出的目标。

```powershell
hdc install -r .\LittleGames-1.1.1-signed.hap
hdc shell aa start -a EntryAbility -b com.littlegames.collection
```

**保留数据升级时请沿用原签名。** 如果系统报告签名不匹配，请保留原安装，找回原签名配置后重试。卸载或清除应用数据会删除本机战绩与存档。

## 用对应源码在 DevEco Studio 运行

从 GitHub 获取版本标签，打开仓库根目录并同步工程。

```shell
git clone --branch v1.1.1 --depth 1 https://github.com/wujiyan19/PocketJoy.git
cd PocketJoy
```

在 DevEco Studio 中配置自己的签名和目标设备后，使用 **Run** 构建并安装。需要 Release 构建时，在仓库根目录执行 `node scripts/build-hap.cjs release`，产物位于 `entry/build/default/outputs/default/`。

## 安装后可核对的内容

在「我的」→「设置」→「关于软件」查看版本号。目录应有 60 款游戏，数学挑战与节奏落键的模式合计后共有 65 种玩法。可以打开打地鼠、华容道或切水果查看新背景。覆盖升级后，可在原设备打开「我的」和「精选」查看战绩及待续对局。[版本说明](https://github.com/wujiyan19/PocketJoy/blob/v1.1.1/docs/release/v1.1.1.md) · [发布回执](https://github.com/wujiyan19/PocketJoy/blob/v1.1.1/docs/release/v1.1.1-verification.json)
