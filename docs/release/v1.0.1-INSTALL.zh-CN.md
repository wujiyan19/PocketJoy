# 玩趣盒 1.0.1：安装说明

下载 `LittleGames-1.0.1-release-unsigned.hap` 和 `SHA256SUMS.txt`，先核对 SHA-256。附件是 **Release 编译模式的未签名 HAP**，安装前须使用自己的合法证书与适用设备的 Profile 完成签名。

包名：`com.littlegames.collection`；版本：`1.0.1`；versionCode：`1000001`。
目标 SDK：HarmonyOS API 26；最低兼容：HarmonyOS 6.1.1 / API 24。工程支持 phone / tablet，实际覆盖以验证报告为准。

## 从对应源码运行

1. 安装 DevEco Studio 26.0.0.851 或兼容 API 26 的工具链。
2. 获取仓库并切换对应标签：

   ```shell
   git clone https://github.com/wujiyan19/PocketJoy.git
   cd PocketJoy
   git checkout v1.0.1
   ```

3. 用 DevEco Studio 打开工程并同步依赖，连接符合系统要求的设备。
4. 按华为官方流程配置自己的签名、设备授权，再通过 IDE Run 构建安装。命令行使用 `node scripts/build-hap.cjs release`；本地签名可放在根目录忽略文件 `signing.local.json`，其顶层包含构建配置对应的 `signingConfigs` 与 `products`。不要提交个人签名材料或口令。

也可使用华为官方签名工具对下载的未签名 HAP 签名。请按当前工具文档操作：[应用签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing)。

从旧版本保留数据升级时，应沿用原包名和签名。若签名不同，系统会拒绝覆盖；请保留原应用及数据，不要直接卸载后重装。
