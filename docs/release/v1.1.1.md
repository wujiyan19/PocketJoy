# 玩趣盒 1.1.1 · 对局背景更新

玩趣盒 1.1.1 更新了 60 款游戏、65 种玩法的对局背景。圆角棋盘、柔和配色和浅色、深色主题继续采用玩趣盒原有风格。绘制细节集中在场地边缘，棋子、障碍、计时和操作提示仍是画面重点。[完整玩法目录](../../README.md#玩法目录)

## 打开游戏后能看到什么

- **打地鼠**的草地边缘加入了矮灌木、木栅和碎石，九个洞口之间留出干净的草地。
- **华容道**使用带细木纹和黄铜接头的枫木托盘，底部金色标记指向出口。
- **节奏落键**换成柔光舞台，四轨判定线和节拍跳跃提示在各自的游玩区域里清晰可见。
- **切水果**的砧板加入了胡桃木纹和凹槽，木纹在水果经过的区域更轻。

打砖块加强了浅色与深色主题下的小球轮廓，宝石三消在最右列与盘沿之间留出了间距。「我的」中最近游玩和常玩排行现在可以直接打开对应游戏，分类筛选为每个类别提供了独立图标。包内清理了已下架玩法的音效和不再使用的图片，也合并了两套三维主题的重复几何数据。[应用优化记录](../project-optimization-suggestions-2026-11-20.md#2026-年-11-月-22-日复核与处理)

## 下载与安装

应用包名为 `com.littlegames.collection`，内部版本号为 `1001001`。使用 HarmonyOS API 26 构建，适用于 HarmonyOS 6.1.1（API 24）及以上的手机和平板。GitHub Release 提供以下附件。[下载 v1.1.1](https://github.com/wujiyan19/PocketJoy/releases/tag/v1.1.1)

| 附件 | 用途 |
| --- | --- |
| `LittleGames-1.1.1-release-unsigned.hap` | Release 模式编译的未签名 HarmonyOS 开发包，约 8 MB |
| `INSTALL.zh-CN.md` | 签名、安装和保留数据的升级步骤 |
| `SHA256SUMS.txt` | HAP 和安装说明的 SHA-256 校验值 |

沿用旧版使用的签名覆盖安装，可保留当前设备上的记录和待续对局。[安装与升级步骤](v1.1.1-INSTALL.zh-CN.md)

## 验证范围

API 24 手机模拟器上的美术候选包完成了 65 种玩法的浅色开局采图和 11 个代表页面的深色开局采图。Gemini 逐页审核浅色对照，核对背景渲染、主体辨识度和遮挡，返修页面通过复审。39 套桌面回归共 1,482 项全部通过。[桌面回归结果](v1.1.1-regressions.json)

API 26 手机模拟器使用本地签名的 Release 包从 1.1.0 覆盖升级到 1.1.1。重启应用后继续原来的 2048 和数独对局，两款棋盘均与升级前一致。[发布回执](v1.1.1-verification.json)
