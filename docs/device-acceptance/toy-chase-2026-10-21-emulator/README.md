## 复验

在项目根目录设置明确目标和证据目录后运行：

```powershell
$env:LITTLEGAMES_ART_TARGET='127.0.0.1:5555'
$env:LITTLEGAMES_ART_OUTPUT='docs/device-acceptance/toy-chase-2026-10-21-emulator'
$env:LITTLEGAMES_ART_HAP='E:/lianxi/LittleGames/.local-tools/toy-chase/entry-debug.hap'
node scripts/device-toy-chase.cjs fronts
```

`blackhole` 操作需要先打开一局待开始的黑洞游戏；`difficulty 简单` 可切换难度；`drift` 是截图辅助的交互观察，会如实输出是否获胜，并非完整通关验收通过的断言。图像识别只读取渲染截图，操作只经 HDC 官方 UI/输入工具发送，不读取或注入应用存档和关卡状态。

手机的触控手感、持续帧率、发热和耗电仍需连接真机后验证。没有做提交或推送，原有本地签名配置保留。
