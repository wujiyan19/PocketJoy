# 游戏去留与复玩整改执行记录（2026-10-27）

已按用户确认落实[全游戏审核](game-retention-audit-2026-10-27.md)：当前为 **64 个独立入口，保留 69 个原有玩法**；新增暂撤 7 款、合并 5 个入口，并对 26 款保留项实施本轮整改。原模型、资源、原始战绩保留。未提交或推送 Git，未改本地签名配置；工作区原有黑洞、漂移与棋类等改动继续保留。

## 目录与模式承接

- 暂撤：跳一跳、落槽配对消除、记忆缺项、沙画吸色、画线救援、保龄球、管道连通。统一上架策略同步影响目录、搜索、推荐、路由、历史统计和接续；旧模型仍可独立回归。
- 数学挑战保留心算、比大小、数列、二进制、补数五模式；节奏落键保留四轨落键、三键节拍跳跃两模式。切换进行中的模式先提示当前进度将重置。
- 旧模式最高分仍可查看；新成绩按模式及难度分别保存。合并模式的时长、真实开局次数、最近日期和历史列表汇总到主入口，原始记录不重写；新开局不会再次累加旧记录。
- 原数学/节拍独立入口的旧接续导航映射至主入口，保留原模式棋盘与进度。新增七款暂撤项不接受公开路由或整应用接续。
- 六类入口数依次为：街机休闲 16、逻辑解谜 24、棋盘对弈 5、数字训练 4、记忆专注 4、反应节奏 11。README、中英文文案、目录/音效断言与设备目录脚本同步。

## 26 款保留项逐项落实

| 游戏 | 本轮实现 |
| --- | --- |
| 2048 | 原简单/普通/困难改为明确的 4 方块出现概率 5%/10%/20%；当前规则最佳分开记录，含旧版的历史总最高分保留展示。切换规则前先结算原规则成绩。 |
| 打地鼠 | 新局三档统一 30 秒，出现速度仍分档，按档保存成绩。旧版 40/30/20 秒对局可接续，其成绩放入旧版记录，避免与新规则混榜。 |
| 数独 | 在唯一解与提示量之外增加显性唯一数/隐性唯一数评级；简单、普通按对应技法筛题，困难要求两种技法无法直接完成，并显示实际技法提示。生成次数有既有上限，回退题也按对应评级验证。 |
| 华容道 | 从三种经典基础布局沿合法移动生成不同局面，避开已完成状态；保留同组棋子与旧存档兼容。此次增加可解变化，不将其说成已制作完整的人工关卡库。 |
| 汉诺塔 | 随机初局与目标柱，显示精确最少步数；增加实际游玩计时与分档最佳用时。旧存档沿用原第三柱目标，不凭空显示未知初始最优步数。 |
| 跳子独留 | 扩大为 21 孔棋形，逆向生成 4/7/10 步残局；通过合法反向跳跃保持可解。原 13 孔存档仍可继续。 |
| 数字绘格 | 新题经过行列候选传播筛选，提供“标空”工具；旧题继续接受符合全部行列线索的解，旧存档不冒称已通过新筛题。 |
| 数字寻序 | 增加实际用时及各档最佳用时；切后台、设置遮挡和退出确认期间不计时，接续保留已用时间。 |
| 方块拼填 | 新局三档统一 6×6 面积，避免困难档反而获得更多空间；以块形复杂度和目标分形成梯度，困难档纳入十字块。旧 7×7/8×8 存档继续可用。 |
| 落果合成 | 移除无效难度按钮，保留统一规则和既有随机供给、物理合成；新记录使用标准模式。 |
| 跑酷闯关 | 将“无尽跑酷”改为“跑酷闯关”，与达到目标后结算的实际规则一致；保留当前速度与障碍梯度。 |
| 推箱子 | 新局加入不同内部墙形，仍使用逆向拉箱构造可行路线；保留旧仓库与存档。未把箱数或拉动次数称为人类难度评级。 |
| 经典纸牌 | 移除无效难度按钮，明确保留当前单张翻牌规则；不将三档说成单张/三张模式。 |
| 绳结解开 | 将固定中心轮图改为不同的环与随机平面三角剖分子图，随机摆放结点；保留无交叉布局作为生成依据。旧轮图存档仍可用。 |
| 横版跳跃 | 新局随机平台宽度、间距与高度，随档增加间距/减少宽度；继续要求真实跳跃，避开只延长终点的旧结构。 |
| 钩索摆荡 | 新局随机平台与锚点位置，沿用真实绳长约束与释放操作；不再固定重复两种锚点高度。 |
| 滚动球 | 新局改变挡板的开放方向、纵向位置及终点；保存一条可行路线用于生成验证。挡板保持原有宽度，使 3D 场景和碰撞尺寸一致，旧地图存档兼容。 |
| 坦克对战 | 增加随机掩体；坦克绕障，掩体同时阻挡双方炮弹，需要选择射线位置。仍保留自动炮台，未宣称已改为方向手动开炮。 |
| 自动攻击生存 | 增加攻击、射速、回血三种局内升级选择，以及速度/耐力不同的敌人；升级与生存状态进入存档。 |

| 爬坡越野 | 新局随机地形相位与波长，随档改变起伏幅度；显示与物理读取同一地形。新地形参数存档，旧正弦地形继续可用。 |
| 蜘蛛纸牌 | 移除无效难度按钮，保留当前按点数连序的规则；不声称已有一/二/四花色强度分档。 |
| 空当接龙 | 移除无效难度按钮，保留当前四空当与搬牌容量规则，按标准模式记录。 |
| 图片拼图 | 从一张图扩为四种现有原创画面，新局随机选择；每幅图按难度单独记录成绩，画面选择随存档保存。 |
| 旋律记忆 | 移除无效难度按钮，保留四音、逐轮增长的标准规则及音频回放。 |
| 休闲钓鱼 | 六种鱼采用不同拉力/挣扎/收线参数，显示鱼种提示和本局收集；以张力控制表现计分，取消随机颜色直接决定分值。旧鱼局仍可继续。 |

“困难需进一步推理”只表示显性/隐性唯一数不能完成，不承诺全部困难题都能由某一套高级人类技法无试探完成。华容道、汉诺塔等的用时或最少步记录与真实人类难度分布也是不同证据。
