# 黑洞吞噬与单键漂移 — 2026-10-21

延续统一的玩具感、简洁造型、适度材质细节和固定镜头。

## 美术与手机开销

- 黑洞使用 ArkGraphics 3D 原生场景。55 个玩具槽复用球、方块、路锥、桶、小屋和叠块，绿圈表示当前可吞噬。吞入时模型下沉、缩小。
- 漂移使用原创 3D 玩具车的透明预渲染图，搭配原生绘制的连续赛道。转向同步改变车身倾斜，赛道前方与碰撞规则使用同一条曲线。
- 新增两份无贴图 GLB 各 525,796 字节，以及 3,507 字节车图，合计约 1.01 MiB。Three.js 和浏览器只用于开发期生成资源，不进入应用。
- 固定正交镜头、80% 黑洞渲染分辨率、预分配对象槽；静止玩具只在换局时写入变换，成长时更新可吞噬提示，移动和下沉才逐帧更新。
- 原生节点只遍历一次并缓存，释放场景时一并清除。首次验证发现的重复遍历造成加载阻塞，已修正并加入回归。

## 随机规则与通关条件

黑洞每局保存独立种子，随机打乱网格位置并轻微扰动。三个难度分别收集 35、45、55 件玩具。生成器同时构造合法的逐步成长路线，确认黑洞长大后仍能在边缘吞到物体，并按移动距离、逐件观察时间和额外余量设置倒计时。

漂移每局生成不同的平滑曲线。弯道每段持续 4 秒，最大横移 64，最大道路横向速度为 24，低于汽车 78/86/94 的转向速度。开局前 4 秒保持直路，起步速度逐渐提升。难度越高，道路越窄、持续时间越长，车身半径也计入出界判断。

新局重新生成，暂停、后台和续玩保留同一局面。继续支持旧版黑洞存档与正弦赛道存档；新存档会校验种子、物体位置、成长、赛道和时间预算，拒绝损坏数据。

## 验证

`node scripts/test-toy-chase.cjs` 对每款游戏、每个难度各测试 1,000 个种子，共 6,000 局：

- 黑洞独立控制器每 300ms 观察、选择最近可吞物体，3,000 局全部获胜，最长约 19.04 秒。
- 漂移独立控制器每 200ms 观察并切换方向，3,000 局全部获胜。三个难度最大采样中心偏差约 30.29/31.91/33.55，允许的偏差分别为 54/48/42。
